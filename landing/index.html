Frequently asked questions

Concrete operational specifications for security teams.

Does any telemetry touch physical disk storage?

No. All file parsing executes inside volatile memory byte streams. Buffers are purged immediately after tensor preparation.

How does local demasking maintain compliance?

The cryptographic lookup vault lives strictly within the local application memory. When an external language model returns MITRE mappings, the substitution happens locally on your browser screen.

What happens if no external API key is provided?

Antigravity features a deterministic cyber heuristic engine that synthesizes complete YARA, Snort, and iptables rules offline without calling any cloud service.

Which machine learning architectures are benchmarked?

Logistic Regression, Random Forest, XGBoost gradient boosting, and a Deep Multi Layer Perceptron neural network with dropout and ReLU activations. Unlabeled sets trigger the Deep Autoencoder.

How is the evasion resistance score calculated?

We measure baseline F1 detection score against synthetic Laplacian and Gaussian noise perturbations across multiple epsilon levels, scoring the percentage of retained defensive efficacy.

Is this platform open source?

Yes. Distributed under the standard MIT License. You can inspect, modify, and host the code internally without vendor licensing restrictions.
